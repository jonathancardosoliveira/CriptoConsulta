## 📌 Sobre o Projeto
 
O **CriptoConsulta** é uma aplicação Java desenvolvida como projeto prático da disciplina de **Programação Orientada a Objetos (POO)** da Universidade Tecnológica Federal do Paraná (UTFPR).
 
O objetivo principal foi aplicar os conceitos fundamentais de POO — como encapsulamento, herança, polimorfismo e abstração — em um contexto real, integrando a aplicação com uma **API externa** para buscar e exibir o **preço atual do Bitcoin** e outras criptomoedas.
 
---
 
##  Funcionalidades
 
-  **Consulta de preço do Bitcoin** em tempo real via API
-  Exibição de informações de mercado da criptomoeda
-  Integração com API RESTful usando requisições HTTP em Java
-  Estrutura orientada a objetos com separação clara de responsabilidades
-  Conversão e formatação de valores monetários
